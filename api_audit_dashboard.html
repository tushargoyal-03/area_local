POST /api/auth/refresh Public
Pending Integration
Accepts a refresh token, verifies its cryptographical integrity, and rotates the credentials by issuing a fresh pair of access and refresh tokens.
🚨 Expired Access Tokens Cause Crashes
The Flutter client's network layer (dio_service.dart / app_config.dart) has no interceptor to automatically intercept 401s, hit the refresh endpoint, rotate tokens, and retry the request.
  • Implement a custom Dio Interceptor to watch for 401 responses.
  • Make a request to /auth/refresh with the stored refresh token on 401.
  • Store the new rotated keys in SecureStorageService and re-try the initial request.

GET /api/posts/nearby Public
Partially Integrated
Retrieves a localized feed using MongoDB's $geoNear pipeline. Supports geohash boundary optimizations and has dynamic radial fallbacks when local densities are low.
⚠️ Array vs Atomic Counter Scale Mismatch
Backend removed the infinite interestedUsers array on post objects for DB performance. The frontend, however, still parses post['interestedUsers'] as an array of user IDs. Because it is absent, interest flags always resolve to false on initial feed load.
  • Update backend query to accept caller JWT, or support an optional userId parameter on this endpoint.
  • Inject a customized boolean isInterested directly into the projection stage of findNearby().
  • Modify posts_repository_impl.dart to check the direct boolean field isInterested instead of calculating it via array lookups.
